# Rencana implementasi katalog

Tujuan: katalog Koleksi dan E-Book terhubung Next.js, NestJS, dan MySQL tanpa mengubah auth atau fitur peminjaman.

Arsitektur: model Book dan BookCopy, API publik read-only, query pencarian/filter/sort/pagination di database. Dua halaman memakai komponen katalog, navbar dan footer reusable. State pencarian berada di URL; detail dan kerangka viewer memakai route terpisah.

- [x] Tambahkan schema, migration non-destruktif dan seed development idempoten (12 fisik, 8 e-book). Pertahankan users/member_profiles.
- [x] Implementasikan CollectionsModule: daftar, metadata filter, detail, daftar e-book. Hitung status dari eksemplar; relevansi memakai urutan SQL terparameterisasi.
- [x] Hubungkan proxy Next.js, katalog responsive, filter dialog mobile, grid/list, chip, pagination dan state permintaan.
- [x] Tambahkan detail dengan CTA peminjaman persiapan, serta viewer e-book tanpa download utama. Gunakan cover lokal existing.
- [x] Verifikasi database/API, UI desktop/mobile, TypeScript dan regresi auth. Lakukan satu review akhir dan laporkan ringkas.

Keputusan: chip E-Book pada katalog khusus berpindah ke katalog umum jika dihapus; Bersihkan tetap membatasi halaman E-Book pada EBOOK. Filter kategori berasal dari metadata database. CTA pinjam hanya menampilkan keterangan persiapan modul, tanpa membuat transaksi. E-book tanpa file menampilkan state belum tersedia.

Hasil: migration diterapkan, seed tersimpan di MySQL, API dan browser diuji pada 1440/390/320px. TypeScript/lint bersih; 29 tes auth lolos. Review akhir menemukan toolbar sempit; diperbaiki dengan wrapping. Bersihkan membatalkan debounce pencarian. Tidak ada transaksi peminjaman atau CRUD admin baru.
